# 光纤熔接成像仿真与接头管理系统

纯前端系统：TypeScript + WebGL2（自写 GLSL 光线追迹着色器，无任何图像纹理）+ IndexedDB 本地持久化。
面向光缆接续班组的培训与接头质量管理，覆盖光缆路由、接头盒成端、熔接机侧视成像仿真、OTDR 曲线、工单统计五个页面。

## 启动

```bash
npm install
npm run dev      # 开发服务器（默认 http://127.0.0.1:5235）
npm run build    # 类型检查 + 生产构建到 dist/
npm run preview  # 预览生产构建
```

首次打开自动写入一套演示数据（一条主干路由、2 个接头盒、8 个示例接头、1 条 OTDR 曲线、3 名熔接员）。
清空浏览器 IndexedDB（库名 `fiber-splice-sim`）后刷新即重新播种。

## 五个页面

| 路由 | 页面 | 功能 |
| --- | --- | --- |
| `#/route` | 光缆路由 | 按段维护芯数/十二色色谱/段长/盘留/IOR，SVG 线路示意图，点接续点直达接头盒，可新增接续点 |
| `#/box` | 接头盒 | 熔纤盘分页，十二色+色环纤芯，HTML5 拖拽建立 A/B 端熔接，直熔/跳接分标，超标红色标记 |
| `#/bench` | 熔接台仿真 | X/Y 双相机 WebGL2 侧视图、缺陷参数滑块、对芯/放电动画、三列损耗对照、像素级偏心自检 |
| `#/otdr` | OTDR 曲线 | SOR（Telcordia 743 容错解析）/CSV 导入或手录，事件标注、双向平均、增益假象提示、IOR/距离校正、接头盒台账核对 |
| `#/orders` | 工单统计 | 按盒派工、超标接头自动返工单、熔接员平均损耗/返工率、成端表与测试记录 CSV 导出 |

## 侧视成像的物理实现（核心）

`src/sim/shaders.ts` 的片元着色器对每个传感器像素反向追迹一条远心平行光：

1. **Snell 折射**：GLSL `refract()` 处理包层外壁、纤芯、G.657 沟槽层、端头、气泡壁各界面；全反射走 `reflect()` 继续传播。
2. **Fresnel 反射**：s/p 分量平均的界面反射率逐次累乘透过率。
3. **亮纤芯线**：相邻两条入射光线的出射位置雅可比 `|Δy_out/Δy_in| < 1` 表示柱透镜会聚，辐照度升高；再叠加随 Δn 增强的模场高斯聚焦项。
4. **两侧暗边**：雅可比 >1 的发散区 + 出射方向偏转被远心孔径指数拦光（`aperture = exp(-k·deflect²)`）。
5. **缺陷几何全部参与追迹**：切割角改变端头平面、包层直径偏差改外壁半径、纤芯偏心平移纤芯圆柱、污染在端面附近吸收、气泡是玻璃内空气空腔、熔细按距端头距离收缩半径。
6. **放电**：电弧辉光按端头距离高斯衰减并带闪烁；电流 <0.88 或时间 <1200ms 概率出气泡，电流 >1.12 或时间 >2300ms 出现熔细。

全程无贴图、无烘焙，参数改动后下一帧即重新追迹。

## 损耗模型（与图像共用同一套微米几何）

`src/sim/loss.ts`，单位全部为 μm/dB：

- 横向偏移（单模高斯）：`L = 4.343 · 2d²/(w₁²+w₂²)`；同纤 G.652（MFD 10.4）下
  **偏心 0.5μm → 0.040dB，1.0μm → 0.161dB**，与侧视图亮线质心偏移像素一一对应（已用 `readPixels` 验证质心随偏心单调、近似线性移动）。
- 多模 50/125 用阶跃孔径重叠公式 `L = -10log[2/π(acos q - q√(1-q²))]`。
- 轴向倾角：`4.343·(π n w θ/λ)²`；模场失配：`-10log[4w₁²w₂²/(w₁²+w₂²)²]`；间隙项按 ~0.002dB/μm 工程标定。
- 三列对照：仿真估算 / 熔接机显示（带正偏置与固定种子噪声）/ OTDR 双向实测（含背向散射方向项，单向负值标增益假象）。
- 返工阈值 `LOSS_LIMIT_DB = 0.08dB`，熔接台保存超标接头时自动生成返工单。

## 目录结构

```
src/
├── data/        # IndexedDB 封装、光纤参数/色谱、演示种子
├── sim/         # GLSL 着色器、WebGL2 渲染器、动画状态机、损耗公式、SOR 解析
├── pages/       # 五个页面
├── ui/          # 哈希路由、DOM 辅助、熔接台控件
├── types.ts     # 全部数据模型
└── main.ts      # 入口与外壳
```

## 浏览器要求

需要 WebGL2（Chrome/Edge 90+、Firefox 90+）。数据仅存本机 IndexedDB，不发起任何网络请求。
